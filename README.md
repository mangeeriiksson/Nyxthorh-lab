## About

Nyxthorh Lab is my personal homelab, built to develop practical experience in infrastructure, systems administration, virtualization, and cyber security.

The environment serves as a platform for exploring enterprise technologies, validating architectural decisions, and documenting lessons learned through real-world implementation. Every project is approached with the goal of improving technical understanding while building a stable and maintainable infrastructure.

This repository contains the public documentation for the lab. Sensitive configurations, operational details, and environment-specific information are intentionally excluded.

## Design Principles

The lab is built around a number of long-term engineering principles:

- Build with a clear purpose.
- Keep the architecture modular.
- Prefer simplicity over unnecessary complexity.
- Document decisions as the environment evolves.
- Validate changes before relying on them.
- Continuously review and improve existing solutions.

The objective is not to build the largest possible homelab, but to build one that remains understandable, maintainable, and useful as new technologies are introduced.

---

## Security

Only documentation considered safe for public release is published in this repository.

The following information is intentionally excluded:

- Infrastructure-specific configurations
- Credentials and secrets
- Network addressing
- Firewall policies
- VPN configurations
- Detection logic
- Automation scripts
- Certificates and cryptographic material
- Environment-specific operational details

This repository is intended to demonstrate engineering practices and technical understanding without exposing information that could weaken the operational environment.
