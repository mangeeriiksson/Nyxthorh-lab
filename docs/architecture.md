# Architecture

## Overview

Nyxthorh Lab is a personal infrastructure and cyber security homelab designed for continuous learning, experimentation, and documentation.

The environment is built around a virtualized infrastructure where services can be deployed, tested, rebuilt, and documented without affecting production systems.

Rather than focusing on a single technology, the lab combines multiple disciplines to better understand how modern IT environments are designed, operated, monitored, and secured.

## Core Areas

The lab currently focuses on:

- Infrastructure and virtualization
- Networking and segmentation
- Windows and Linux administration
- Active Directory
- Security monitoring and logging
- Threat detection and analysis
- Automation
- Home automation
- Video surveillance

## Design Principles

The environment follows a few core principles:

- Security by default
- Separation of services
- Reproducible deployments
- Continuous improvement
- Documentation before complexity

## Public Documentation

Only high-level architecture is documented in this repository.

Operational details such as addressing information, credentials, certificates, firewall policies, VPN configurations, and environment-specific implementation details are intentionally excluded.
