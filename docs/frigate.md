# Frigate

## Overview

Frigate provides intelligent video surveillance within the Nyxthorh Lab.

Rather than functioning solely as a recording platform, it combines video processing with object detection to improve situational awareness while reducing unnecessary recordings and notifications.

The platform demonstrates how modern computer vision can be integrated into a self-hosted infrastructure.

---

## Objectives

The surveillance platform is designed to achieve several objectives:

- Improve awareness of activity around the environment.
- Reduce false alerts through intelligent object detection.
- Maintain local control over surveillance data.
- Integrate with the wider infrastructure where appropriate.
- Provide a practical environment for learning and experimentation.

The focus is on useful information rather than continuous recording alone.

---

## Design

The surveillance platform is built around local processing.

Video streams are analysed within the infrastructure, allowing object detection and event generation without depending on external cloud services.

This approach improves privacy while providing greater control over both data and system behaviour.

As the environment evolves, additional cameras and detection capabilities can be incorporated without changing the overall design philosophy.

---

## Operational Philosophy

Surveillance should provide meaningful information without becoming intrusive.

Detection quality, reliability, and operational simplicity are prioritised over collecting excessive amounts of footage.

The system is intended to support the infrastructure, not create unnecessary operational overhead.

---

## Lessons Learned

Modern surveillance is most valuable when it delivers context rather than simply recording video.

Local processing, careful system design, and thoughtful integration create a platform that is both practical and educational while maintaining full control over the generated data.
